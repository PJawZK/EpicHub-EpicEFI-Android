# EpicEFI – EpicHub

EpicHub is a new Android application for EpicEFI, designed as a clean-slate successor to the earlier EpicDash/EpicDash-JZ work.

The application is being designed around a Kotlin/Jetpack Compose Android layer and a Rust engine for high-volume ECU, measurement, logging, analysis, and tuning work. Existing EpicDash, EpicDash-JZ, EpicEFI firmware, and related projects are reference/evidence sources; their source-tree structure is not authoritative for EpicHub.

## Current phase

Phase 1: cross-repository responsibility inventory and codebase architecture.

No production Android or Rust implementation should be added until the Phase 1 architecture contracts establish ownership, boundaries, naming, and target topology.
